# 🏫 Smart College Complaint & Resolution System

A web-based system that helps students **submit, track, and manage college complaints** digitally.

## ✨ Features

* 📝 Submit complaints
* 🎫 Generate Complaint ID
* 🔍 Track complaint status
* 🏢 Assign complaints to departments
* 📊 Admin dashboard
* 🔄 Update complaint status

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* LocalStorage

## 🚀 How to Run

1. Clone/download the repository.
2. Open `index.html` in a browser.
3. Submit and track complaints through the system.
